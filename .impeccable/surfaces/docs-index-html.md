# Surface: Report Checker showcase (docs/index.html)

Scope: static GitHub Pages showcase in /docs, data generated by scripts/build_site.py. Visitor mode: Experience
(the work leads from the first viewport). Audience: a hiring manager at an AI / intelligence startup, cold, ~2 minutes.
Job: see a wrong number caught with its proof, then understand the engineering judgment behind it.
Must leave believing: it catches real errors with proof, and the author builds trustworthy AI systems.
Constraints: calm, professional, no AI-template gloss; honest about the partial frozen run, tuning on the same set,
and the pending held-out test. LinkedIn link hidden until a URL is supplied.
Memorable moment: hovering a ticked figure pulls the auditor's note into the margin: what the data says and the SQL.
Unresolved: LinkedIn URL; held-out result (placeholder).

## Direction contract

THESIS: The site is an auditor's working-paper file on one analyst report. Every figure carries a tick mark that
points to its evidence. It refuses the AI-showcase default of a hero headline, feature cards and metric tiles.

OWN-WORLD: Pale ledger-green columnar pad ground with printed dark-green rules; coloured-pencil tick marks drawn as
strokes (blue agreed, red circled exception, ochre unsupported, brown does-not-foot, graphite not verified); a
printed working-paper header block (client, period, prepared by, reviewed by, W/P ref); index tabs down the edge;
tabular numerals; a tick-mark legend on every sheet. Red appears only on figures the data contradicts.

STORY: The visitor lands on W/P B-1, a real report already ticked. They hover a red-circled figure and read the data
and the query in the margin, switch tabs to another report, read coverage (C), the review notes (D), the testing
summary in plain words (E), and the procedure (F), then the preparer's sign-off with links.

FIRST VIEWPORT: Full-width working-paper sheet. Top header block: title "Report Checker" with the one-line pitch as
the purpose line, the why as the preparer line, W/P ref B-1. Left: report index tabs 01-10. Centre: report text with
pencil ticks in a margin column. Right: the tick-mark legend and the live margin note. No button row.

FORM: Auditor's working papers with tick-mark legends; my rank 1 of 7, chosen by the user as IMPECCABLE'S PICK over
the assigned rank 6. seed: 8644474d648eae59

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
